# 👑 KING WORDS — English Vocabulary Trainer

أداة شخصية لتعلم وحفظ الكلمات الإنجليزية: معنى بالعربي، جملة توضيحية مع ترجمتها، نطق حقيقي (طبيعي وبطيء) للكلمة والجملة، كلمات وجمل صعبة، سجل مفردات، واختبار تفاعلي.

**المشروع الآن Frontend فقط بالكامل** — HTML + CSS + Vanilla JavaScript بدون أي framework، بدون Node.js، بدون Express، بدون SQLite. كل شيء يعمل مباشرة من المتصفح، والحفظ يتم بالكامل عبر `localStorage` بحيث تبقى بياناتك موجودة حتى بعد إغلاق المتصفح وإعادة فتحه.

## 1. طريقة التشغيل

⚠️ **مهم جدًا:** لا تفتح `index.html` بالنقر المزدوج مباشرة (`file://`) — المتصفح يحظر أي اتصال بأي API خارجي (مثل القاموس والترجمة) من الصفحات المفتوحة كملف محلي، بغض النظر عن إعدادات الـCORS الخاصة بالـAPI نفسه. هذا يظهر برسالة "Unable to connect to the dictionary service" رغم أن الكود والـAPI سليمان تمامًا. استخدم دائمًا إحدى الطريقتين التاليتين (كلاهما يفتح الموقع عبر `http(s)://` وليس `file://`):

- **VS Code + Live Server (المستحسن للتطوير المحلي):** افتح مجلد المشروع في VS Code، اضغط بزر الفأرة الأيمن على `index.html` → **Open with Live Server**. سيفتح الموقع على رابط مثل `http://127.0.0.1:5500`.
- **GitHub Pages:** ادفع المشروع كاملًا إلى مستودع GitHub، ثم من إعدادات المستودع **Settings → Pages** اختر الفرع (Branch) الذي يحتوي المشروع والمسار الجذري (`/`)، واحفظ. سيعطيك GitHub رابطًا عامًا مثل `https://username.github.io/repo-name/`.

لا حاجة لـ `npm install` ولا لأي سيرفر Node — المشروع ملفات ثابتة (Static) فقط، لكنه **يجب** أن يُقدَّم عبر بروتوكول `http` أو `https` لكي يعمل البحث.

### إذا استمر ظهور الخطأ بعد استخدام Live Server

الكود الآن يسجّل السبب الحقيقي في الـConsole (اضغط `F12` → تبويب **Console**) بدل الاكتفاء بالرسالة العامة. افتح الـConsole وأعد البحث، وستجد سطرًا يبدأ بـ`KING WORDS: dictionary fetch failed` أو `KING WORDS: dictionary API returned HTTP ...` يوضح السبب الفعلي (مثلًا حجب من إضافة متصفح كـ Ad-blocker، أو مشكلة شبكة محلية). جرّب أيضًا نافذة تصفح خاصة (Incognito) بدون إضافات لاستبعاد أي إضافة متصفح تحجب الطلب.

## 2. مصادر البيانات (تُستدعى مباشرة من المتصفح)

- **Free Dictionary API** (`api.dictionaryapi.dev`) — للنطق (IPA)، ملف الصوت، التعريف، والجملة التوضيحية. مجاني، بدون تسجيل، ومتوافق مع CORS للاستخدام المباشر من الـFrontend.
- **MyMemory Translation API** (`api.mymemory.translated.net`) — لترجمة الكلمة والجملة إلى العربية. مجاني، بدون تسجيل، ومتوافق مع CORS كذلك.

لا حاجة لأي مفتاح API افتراضيًا. إذا أردت رفع الحد المجاني لـ MyMemory مستقبلًا، أضف بريدك الإلكتروني في:
```
js/api.js → KW_API_CONFIG.translationApiKey
```

> **ملاحظة مهمة عن MyMemory:** هذه الخدمة تُرجع دائمًا حالة HTTP ناجحة (200) حتى عند فشل الترجمة الفعلية (مثلًا عند تجاوز الحد المجاني اليومي)، وتضع رسالة تحذير إنجليزية داخل حقل الترجمة نفسه بدل رمي خطأ حقيقي. الكود في `js/api.js` يتحقق الآن من حالة الاستجابة الداخلية (`responseStatus`) ومن نص التحذير نفسه، فإذا فشلت الترجمة فعليًا تظهر رسالة "Arabic translation is not available." بدل عرض نص التحذير الإنجليزي وكأنه ترجمة صحيحة.

> **مزوّد احتياطي تلقائي:** إذا فشلت الترجمة عبر MyMemory (تجاوز الحصة اليومية مثلًا)، يحاول الموقع تلقائيًا عبر **Lingva Translate** (واجهة مجانية بدون تسجيل لخدمة ترجمة جوجل، تدعم CORS) قبل عرض رسالة "غير متوفر". هذا يعمل بالكامل من الـFrontend، بدون أي Backend.
>
> **تشخيص مؤقت في الـConsole:** حاليًا، كل محاولة ترجمة (لكل من MyMemory وLingva) تطبع في Console المتصفح (`F12`): حالة HTTP، حالة الاستجابة الداخلية (`responseStatus` أو `translation`)، النص المُرجَع، وأي رسالة خطأ — حتى تتمكن من رؤية السبب الحقيقي مباشرة إذا استمرت المشكلة. هذا التسجيل مؤقت للتشخيص ويمكن إزالته لاحقًا من `js/api.js` (دالتا `_tryMyMemory` و`_tryLingva`) متى تأكدنا أن كل شيء يعمل بثبات.

## 3. نظام الحفظ (localStorage)

كل البيانات تُحفظ في متصفحك عبر `localStorage` — لا تُرسل لأي سيرفر خارجي، وتبقى موجودة بعد إغلاق المتصفح وإعادة فتحه على نفس الجهاز/المتصفح.

**⭐ الكلمات الصعبة** (`kw_difficult_words`) — لكل كلمة:
`word`, `meaning`, `phonetic` (pronunciation), `audioUrl`, `dateAdded`, `reviewCount`

**📌 الجمل الصعبة** (`kw_difficult_sentences`) — لكل جملة:
`word`, `sentence`, `translation`, `dateAdded`, `reviewCount`

بالإضافة إلى: سجل المفردات الكامل (`kw_vocabulary`)، نتائج الاختبارات (`kw_quiz_results`)، الستريك اليومي (`kw_streak`)، والتفضيلات مثل الوضع الداكن/الفاتح (`kw_preferences`).

## 4. شرح الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | كل صفحات الموقع (الرئيسية، الكلمات الصعبة، الجمل الصعبة، كلماتي، الاختبار، عن الموقع) في ملف واحد، والتنقل بينها بـ JS. |
| `css/style.css` | كل التصميم: الألوان، الخطوط، التجاوب، الوضع الداكن/الفاتح، الحركات، وكروت الجمل/الفوتر. |
| `js/storage.js` | طبقة `localStorage` بالكامل: الكلمات الصعبة، الجمل الصعبة، سجل المفردات، نتائج الاختبارات، الستريك، والتفضيلات. لا يوجد أي اتصال بأي Backend. |
| `js/api.js` | يتصل مباشرة من المتصفح بـ Free Dictionary API (تعريف، نطق، جملة توضيحية) وMyMemory (ترجمة عربية)، مع رسائل خطأ واضحة ومتمايزة. |
| `js/speech.js` | تشغيل النطق عبر `SpeechSynthesis` بسرعتين (عادي/بطيء) للكلمة وللجملة. |
| `js/quiz.js` | منطق الاختبار: خلط الأسئلة، التحقق من الإجابة، حساب النتيجة والدقة. |
| `js/app.js` | المتحكم الرئيسي: التنقل، البحث، عرض الكروت (كلمة + جملة)، صفحة الكلمات الصعبة، صفحة الجمل الصعبة، صفحة كلماتي، صفحة الاختبار، ولوحة الإحصائيات. |

## 5. المميزات المنفذة

- 🔍 بحث عن أي كلمة إنجليزية عبر API حقيقي، مباشرة من المتصفح.
- 🇬🇧 نطق صوتي (IPA) و🇦🇪 معنى بالعربي.
- 📖 جملة توضيحية (Example Sentence) عند توفرها، مع 🇦🇪 ترجمتها العربية.
- 🔊 نطق طبيعي و🐢 نطق بطيء فعليان للكلمة وللجملة (Web Speech API، rate 0.9 / 0.55).
- ⭐ حفظ الكلمات الصعبة و📌 حفظ الجمل الصعبة في `localStorage` بشكل دائم، مع بحث وحذف منفصلين لكل قسم.
- 📚 سجل مفردات كامل (تاريخ التعلم + عدد مرات المراجعة) مع إحصائيات.
- 🔄 اختبار تفاعلي مبني من كلماتك المحفوظة في `localStorage`، مع نتيجة نهائية ونسبة دقة.
- 📊 لوحة تقدم: كلمات متعلَّمة، كلمات صعبة، آخر نتيجة اختبار، وستريك أيام متتالية.
- 🌙 وضع داكن/فاتح مع حفظ الاختيار، وتصميم متجاوب بالكامل.
- ⚠️ معالجة أخطاء دقيقة: كلمة غير موجودة ≠ فشل الاتصال بالخدمة، وجملة/ترجمة غير متوفرة لا توقف باقي بطاقة الكلمة عن العمل.
- 👨‍💻 كرت مطوّر منفصل (سمعان قابيل / Samaan Kapeel) وكرت أكاديمية منفصل (King Academy) في الـFooter.

## 6. تحسينات مستقبلية مقترحة

- تصدير/استيراد الكلمات والجمل المحفوظة كملف (JSON/CSV) للنسخ الاحتياطي أو النقل بين الأجهزة.
- إضافة تكرار متباعد (Spaced Repetition) لجدولة مراجعة الكلمات والجمل الصعبة تلقائيًا.
- دعم PWA (تثبيت الموقع كتطبيق + عمل بدون إنترنت للكلمات المحفوظة).
- إضافة أنماط اختبار إضافية (اختيار من متعدد، سماع ثم كتابة، اختبار جمل).
- في حال الرغبة بمزامنة البيانات بين أكثر من جهاز مستقبلًا، يمكن إعادة إضافة Backend اختياري لاحقًا دون التأثير على عمل الموقع الحالي بـ localStorage.
